     +---->|     step     |----->|     tap     |         b         |               |
     |     | 16-bit shift |      |  step >> k  |------------------>|  full adder   |
     |     |   register   |      |    {pr}     |                   |     1 bit     |         sum

     |     +--------------+                                        |     flop      |              |
     |                                                             |               |              |

     *---->|     pred     |              a                         |               |              |
     |     | 16-bit shift |--------------------------------------->|               |              |

     |     |     {pb}     |                                                                       |
     |     +--------------+                                                                       |
     |            |                                                                               |
     +------------|-------------------------------------------------------------------------------+
                  |               one bit a clock, into the register being updated
                  |
                  *-----------------------------+
                  | pred[15:11]                 | pred[10:6]
                  v                             v
           +--------------+             +---------------+
           |  duty latch  |             |  sigma-delta  |
           |    5 bits    |             |   5-bit acc   |
           |     {pt}     |             |     {pt}      |

                  |                             | carry: one more clock
                  v                             v
           +--------------------------------------------+
           |  compare: high while ramp <= duty + carry  |---------> uo[7] PWM, 1 MHz
           |                    {pt}                    |
           +--------------------------------------------+
                                 ^
                                 |
           +--------------------------------------------+
           |  ramp: 5-bit counter of the 32 MHz clock   |
           |     low 4 bits: which bit is going by      |
           |                    {pw}                    |
           +--------------------------------------------+
